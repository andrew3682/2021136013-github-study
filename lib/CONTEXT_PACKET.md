# CONTEXT_PACKET.md

## 1. 목표 (Goal)
제시된 사용자 인터페이스 시안을 기반으로 입력에 유기적으로 상호작용하는 선언형 To-do 상태 기능을 설계하고, 완료 동작 시 탄성 있는 통통 튀는 스케일 애니메이션 피드백을 제공한다.

## 2. 현재 코드 및 파일 구성
- `lib/main.dart`: UI 레이아웃, `TodoItem` 비즈니스 모델, 상태 관리, `BounceTodoTile` 애니메이션 위젯이 포함된 단일 파일 구성.

## 3. 설계 근거 및 제약 조건 (Constraints)
- **외부 패키지 배제 제약:** 인프라 복잡도를 낮추기 위해 외부 전역 상태관리 패키지를 배제하고 Flutter 순정 단일 위젯 트리 내 에페메럴 상태(`setState`)로 제어한다.
- **계산 상태 최적화:** 남은 할 일 개수라는 연산 표시값을 전역 변수로 관리할 시 동기화 누수가 발생하므로 원본 리스트 데이터로부터 실시간 도출하는 Getter 패턴을 적용한다.
- **메모리 보존성:** `Column` 내부에서 무한 스크롤 연산 에러를 차단하기 위해 `shrinkWrap: true` 및 `NeverScrollableScrollPhysics()` 레이아웃 가드를 배치한다.

## 4. 인수 조건 및 검증 절차 (Acceptance Criteria & Verification)
- **AC1 검증:** 초기 앱 구동 시 리스트 2개 배치 및 상단 '남은 할 일 2' 매칭 확인.
- **AC2 검증:** '완료' 탭 이벤트 시 카운트 '1' 감소, 배경색 민트 변경, 글자 취소선, 1.12배 스케일 업 애니메이션이 동시 실행됨을 확인.
- **AC3 검증:** 완료 항목의 '취소' 탭 이벤트 시 데이터 상태 원복 및 상단 카운트 '2'로 복귀, 애니메이션 레이어 원상 복구 확인.
- **AC4 검증:** 코드 내 별도의 정적 카운터 변수가 부재하며 `_remainingTodoCount` 가 매 렌더링 주기마다 동적으로 필터링 연산함을 코드 분석으로 확정.
- **AC5 검증:** 본 패킷 문서 내용과 실제 `lib/main.dart` 아키텍처의 완전 가동성 일치 증명.
